# 数独游戏 (Sudoku Game)

一个基于 **Qt Widgets + CMake + MinGW** 的 Windows 数独游戏。
不需要编译,由作者自己编译
## 项目结构

```
sudoku_game/
├── CMakeLists.txt          # CMake 构建配置（兼容 Qt5 / Qt6）
└── src/
    ├── main.cpp            # 程序入口
    ├── sudokugame.h        # 数独核心逻辑（头文件）
    ├── sudokugame.cpp      # 生成谜题 / 求解 / 验证
    ├── sudokuwidget.h      # 主界面（头文件）
    └── sudokuwidget.cpp    # 9x9 网格界面与交互
```

## 界面布局

- 窗口标题"数独游戏"，最小尺寸 640×640
- 9×9 棋盘在窗口**左侧**：始终**正方形**、格子**零间距紧密相连**、整体居中；3×3 宫格**粗边框**、内部细边框，方便辨认宫格
- **右侧**侧边栏（固定宽度）：控制按钮（新游戏 / 清空 / 生成盘面 / 难度下拉框 / 直接提示复选框）、操作与规则说明、"当前难度"、"无效右键次数"实时显示
- **底部**："提示"按钮在**右下角**，状态栏在**左侧**
- 所有控件随窗口大小按比例缩放（格子数字、按钮、下拉框等字体同步调整）

## 出题规则

- 三种难度：简单 / 中等 / 困难（按每个 3×3 小宫格的空格数区分）
- 随机生成完整解后挖洞出题，挖洞按难度控制**每个 3×3 小宫格的空格数**：
  - **简单**：以 **3 个**为主，**偶尔 1 个**宫格为 **4 个**（约 30% 概率）
  - **中等**：以 **3 个**为主，**至少 2 个**宫格为 **4 个**（2~3 个）
  - **困难**：以 **3 个**为主，**至少 2 个**宫格为 **4 个**，且**至少 1 个、至多 3 个**宫格为 **5 个**
- 挖洞位置按**整盘"行 + 列双重均衡"**选择：每次优先挖"所在行 + 所在列已挖数最少"的位置，空格在整个盘面**均匀分布**（每行/每列空格数尽量均匀、相差最多 1），**不会出现某些行/列空出 5~6 格、而其他行/列几乎没有空格的集中情况**，并保证挖洞后仍有解
- 切换难度下拉框后**自动按新难度开始新游戏**（无需手动点"新游戏"，计时/无效右键次数自动重置）

## 操作与交互

- 玩家在网格中填写 1~9，**初始数字不可修改/删除**（只读）；玩家填写的数字可**自由修改或删除**（Backspace/Delete 可清空格子）
- **自动填写的数字不是永久保留**：玩家**修改**任意数字时，之前自动填写的唯一性数字**全部取消（清空）**并重新自动填写；玩家**删除**任意数字时，**只取消最近一次**自动填写的数字，不重新自动填写
- 点击任意格子（或用 Tab 聚焦），自动高亮该格所在的**行、列与宫格**，辅助判断冲突
- **键盘输入**：选中空格后直接按 1~9 填写
- **直接提示**（仅简单难度显示该复选框，默认**不勾选**）：勾选后点击可编辑格子弹出**候选数字面板**（按数独规则排除同行/同列/同宫已出现的数字，只显示可能填入的数字）；不勾选时不弹面板，键盘输入
- **唯一解提示**：**鼠标右键**点击空格时，若满足以下任一"简单唯一"（帮助玩家省去计算，不过度提示），则弹出面板（只显示唯一数字按钮）；**鼠标左键不弹唯一提示**：
  1. **行列唯一**：该格所在行 + 列排除后只剩 1 个候选（不纳入 3×3 宫格排除）
  2. **宫格内唯一**：该格所在 3×3 宫格内，某个数字只有这一个位置可放
- **数字面板**：显示在格子**右侧**，点击数字按钮直接填入该格；点面板外任意位置或按 **ESC** 关闭；若格子没有候选数字则不弹面板
- **"提示"按钮**：自动填入第一个空格
- **"生成盘面"按钮**：把当前棋盘（9 行 × 9 字符，0 = 空格）复制到剪贴板，可粘贴出来分析
- **"清空"按钮**：清空玩家填写的所有内容（初始数字保留）

## 自动功能

- **自动检查**：没有"检查"按钮——每次填写数字后自动检查，只把**已填写但与答案不同的数字**视为错误（空格不算错误），错误数字标红并在状态栏显示错误数量；没有错误则提示"目前没有错误"
- **自动填写**：填写数字后，只检查该数字所在的**行、列与 3×3 小宫格**，若其中某个区域**只剩最后 1 个空格**，自动填入正确答案（**其他行/列/宫格即使只剩 1 个空格也不自动填写**；仅围绕所填数字的三个区域循环检查，直到没有"最后空格"）；自动填写的数字**不是永久保留**——玩家**修改**任意数字时，之前自动填写的数字**全部取消（清空）**并按规则重新自动填写；玩家**删除**任意数字时，**只取消最近一次**自动填写的数字，不重新自动填写
- **完成提示**：3×3 宫格全部填满后数字变绿色；某**行或列**全部填满且**没有错误**时，该行/列数字也变绿色（错误红色仍优先）

## 统计与完成

- **无效右键**统计两种情形（每次右键最多计 1 次）：① 右键点空格但可选项不是一个（未弹唯一提示）；② 右键弹出面板但**未选择数字**就关闭
- 侧边栏**实时显示**"无效右键次数"；新游戏时清零
- 完成游戏：全部填写正确时弹窗显示本次**用时（分/秒）**和**无效右键次数**，点"确定"后自动生成新游戏并重新计时
- 状态栏反馈信息：
  - 新游戏："新游戏已生成，难度：X"
  - 有错误："发现 N 处错误（已用红色标出）"
  - 无错误："目前没有错误，继续加油！"
  - 提示后："已提示 (行X, 列Y)：Z"
  - 已填满："所有格子都已填满。"
  - 清空后："已清空玩家填写的内容。"
  - 复制后："盘面已复制到剪贴板（9 行文字）"

## 编译方法（由您自行完成）

### 方式一：Qt Creator（推荐）

1. 打开 Qt Creator → `文件` → `打开文件或项目`，选择
   CMakeLists.txt`
2. 选择 **MinGW** 工具链（Kit），点击"配置项目"
3. 点击左下角 **构建**（锤子图标）即可生成 `SudokuGame.exe`

> 提示：如果安装了 Qt6 会优先使用 Qt6，否则自动回退到 Qt5。

### 方式二：命令行

```bat
mkdir build
cd build
cmake .. -G "MinGW Makefiles" -DCMAKE_PREFIX_PATH=C:\Qt\6.x.x\mingw_64
mingw32-make
```

## 常见问题

- 找不到 Qt：确认 `CMAKE_PREFIX_PATH` 指向 Qt 的 `mingw_XX` 目录。
- 编译报错：请把错误信息完整复制给我，我会帮你修复。
